# app-social-poster

> 给 App 截图，稳定产出一套可发社交平台的 3:4 竖版宣传图与配套发布文案（Agent Skill）。
>
> 从实机截图、手机边框素材与 App 定位出发，自动完成版式合成、文案起草、质检与交付，一次给出 4–6 张图、整套总览和一份可直接复制的发布文案。
>
> 作者：**TiantianYe**
>
> 作者在 App Store 中的其他代表作品：水课帮-课堂提问助手；识词本-单词笔记；投影与视图3D教具；解构照片

---

## ✨ 这是什么

- 做 App 推广图时，最容易翻车的不是画图，而是反复返工：配色被否、阴影有硬边、标题里某个字显示错位、文案抄了参考案例、功能描述写错。
- 同一套图还要配一份能直接发小红书／朋友圈的文案，且品牌名不能被营销别称带偏。
- 本技能将整个流程标准化：**素材实测 → 品牌与文案建档 → 图集生成 → 逐条质检 → 文案交付**。
- 首个落地案例是一套 6 张的课堂提问助手宣传图，脚本可像素级复现该定稿。

## 🎯 使用场景

| 要素 | 说明 |
| --- | --- |
| 前提 | 有 4–6 张 App 实机截图，最好附一张屏幕区透明的手机边框 PNG |
| 输入材料 | 截图、App 名称与正式定位、App 描述或功能清单；可选效果参考图 |
| 典型诉求 | 「做一套宣传图」「给这个 App 出小红书配图」「顺便拟标题和文案」「按上次那套再出一套」 |
| 质量要求 | 3:4 竖版、蓝色高饱和渐变、全白超粗大标题、带边框实机截图、柔和阴影、文案抓人且功能准确 |

典型触发指令示例：

> 给你几张新 App 的截图，按 app-social-poster 出一套宣传图，顺便把发布文案写好。

## 🚀 使用方法（工作流概览）

| 阶段 | 内容 | 关键点 |
| --- | --- | --- |
| Stage 0 | 盘点素材、量尺寸、实测边框屏幕透明区 | 屏幕矩形必须像素扫描实测，禁止照抄 |
| Stage 1 | 写 `config.json`：品牌、正式名称、主色、版式 | 正式名称唯一，营销别称不得拼成产品名 |
| Stage 2 | 写 4–6 组标题与发布文案 | 参考案例只学结构；功能描述以用户定稿为准 |
| Stage 3 | 跑脚本出图 | 整行绘制文字、双层带 pad 高斯阴影 |
| Stage 4 | 五步质检 | 目视 + 像素采样 + 红线 grep 全部归零 |
| Stage 5 | 交付图集、总览、文案与日志 | 定稿只读，新 App 写新目录 |

### 输入 / 产出

```
App 实机截图 (4–6 张)  ─┐
手机边框 PNG (可选)     ├─→  01..0N  宣传图 PNG (2160×2880, 3:4)
App 名称 / 定位 / 描述 ─┘      00_整套总览.jpg
                              发布文案.md（七节，可直接复制）
```

## 🔧 环境依赖

- Python 3 + Pillow：用于图像合成、圆角遮罩、渐变背景与高斯阴影。
- macOS 系统字体 `Hiragino Sans GB`：中文超粗大标题与小字的渲染来源。
- `sips` 或 Pillow：量取截图尺寸、验证 macOS 原生解码链。
- `qlmanage`（可选）：刷新缩略图缓存，解决 Finder 预览异常。

## ⚠️ 重要说明

1. **定稿交付物只读**：换 App 一律新建输出目录，不覆盖已认可的成品。
2. **别人的参考案例只学结构与语气，禁止照抄原句**；用户自己重写的文案是权威基准，AI 不得改写其中的功能词。
3. **功能描述必须逐条核对**，尤其是提醒方式、AI 用途、平台列表；不确定的功能宁可不写。
4. 全部文字纯白，品牌条只放 App 名；不加副名、不加英文、不加 emoji（除非明确要求）。
5. 主标题必须整行一次绘制，逐字符绘制会让「一 / 二」这类扁字变成上划线。
6. 阴影必须先给 alpha 四周留透明边再模糊，否则边缘会被硬裁断。
7. 未获明确指令不擅自对外发布任何内容。

## 🐛 已知踩坑点（节选）

- 逐字符绘制中文标题 → 「一」被顶到字格顶部变成上划线；改成整行一次绘制。
- 在手机原尺寸上直接高斯模糊 → 阴影四边硬切断；先留 `blur×3.2` 的透明边再模糊。
- 边框自带灵动岛 + 截图自带灵动岛 → 双岛错位；按截图类型选择清岛后的边框。
- 反复覆盖同名文件 → Finder 缩略图缓存抓到半成品帧变纯黑；清缓存并原子重写文件即可，不是图片损坏。
- 加深背景却没同步减弱光晕 → 顶部仍偏浅，看起来像没改。
- 手机宽度调到 1120 → 底部圆形按钮被裁掉半截；标准档固定 1030。
