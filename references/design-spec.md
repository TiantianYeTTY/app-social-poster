## 〇、v1 → v2 的去AI化改造（为什么改）

用户原话：「我感觉图片还是有"AI味"：一眼看上去就是AI做的图片，缺乏设计感，有明显AI特征。」

| v1（AI味来源，禁止回退） | v2（人味设计） |
|---|---|
| 系统黑体 Hiragino 当主标题 | **得意黑 Smiley Sans**（用户已装 `~/Library/Fonts/smiley-sans-v2/SmileySans-Oblique.otf`）——社媒设计标志字体，自带倾斜速度感 |
| 右上角 `01 / 06` 序号 | **删除** |
| 顶部大光晕 + 右上装饰圆环 | **删除**（光晕是 AI 渲染感重灾区） |
| 两行标题同字号同位置完美对齐 | **字号错落**（行1大行2小）+ 每张不同 tx/ty |
| 标题下白色短线 | **马克笔抖动下划线**（固定 seed 随机抖动，像手画的） |
| 副标题 `A · B · C` 罗列 | **删除副标题行**，信息改由贴纸承担 |
| 品牌条文字 | **白色圆角贴纸**（白底 + 深蓝得意黑字 + 微旋转 + 淡投影） |
| 手机永远居中正放 | 每张不同 **px 偏移 + ±1.6°~2.2° 微旋转**，左右交替 |
| 6 张同构图 | **左右交替布局**：01/04 手机在右、02/05 在左、03 大图右偏、06 居中 |
| 纯净渐变背景 | 渐变 + **细噪点**（`effect_noise sigma=9` 正负半对称叠加，亮度均值不变） |
| 底部居中落款条 | 收尾图右下角得意黑「水课帮」`anchor="rt"` |

### 背景噪点（通道要匹配，注意踩坑）

noise = Image.effect_noise((W, H), 9).convert("RGB")     # 必须转 RGB

im = ImageChops.add(im, ImageChops.subtract(noise, mid))  # 正半
im = ImageChops.subtract(im, ImageChops.subtract(mid, noise))  # 负半

## 二、手绘元素（去AI化的核心组件）

### 马克笔抖动线

```python
def hand_line(d, p1, p2, width, color, seed, wobble=7):
    rnd = random.Random(seed)          # 固定 seed → 可复现
    pts = [(p1[0]+(p2[0]-p1[0])*i/26 + rnd.uniform(-wobble,wobble),
            p1[1]+(p2[1]-p1[1])*i/26 + rnd.uniform(-wobble,wobble)) for i in range(27)]
    d.line(pts, fill=color, width=width, joint="curve")
```
用于第二行标题下方，width=16，白色，每张 seed=1000+idx。

### 大标题字号统一（v2.3，错误档案 #25）

**同字数的大标题字号必须全套一致**（定稿 size1=280 / size2=170）。
曾犯的错：P1「上课摸鱼」300、P2「一键开始」230——按文字区宽度缩字号，
被用户质疑「同为大标题但字号不一致，是刻意还是失误」。正确做法：
放不下时**调文字区起点 tx**（P2 从 1130 左移到 940，文字悬在手机上方空白是安全的，
因为手机 top≥1000 在文字下方），**禁止缩字号**。

### 文字位置视觉带（v2.2→v2.3，错误档案 #24）

6 张大字顶边 `ty` 按布局分两档：**文字在左/中（左上有品牌贴纸压角）→ 330–400**；
**文字在右（右上无贴纸、右上方空）→ 300–320 再上移一档平衡视觉中心**
（用户原话「P2 和 P5 文字在右边，右边文字上方没有水课帮贴纸，需要更往上以平衡视觉中心」）。
ty 定了之后，贴纸 y 跟随 `下划线 y + 45~55` 间隙推算，确保不压线、不碰手机。

## 三、手机合成（最易错，规则同 v1）

- 屏幕透明区 `(72,69)–(1278,2691)` = 1206×2622；截图统一 resize 到此尺寸；
- 屏幕圆角 mask 半径 145；**灵动岛去重**：截图自带岛时清 `(420,85)–(930,360)` alpha；
- **微旋转**：`phone.rotate(tilt, expand=True, resample=BICUBIC)`，再按旋转后轮廓做阴影；
- 阴影：单层 `soft_shadow(blur=80, opacity=0.38, dx=6, dy=48, color=(2,20,62))`，
  `pad = blur×3.2`（带 pad 防硬边是 v1 就立的规矩，不许回退）。
