## 三、手机合成（最容易出错）

边框素材 `iPhone 18 Pro - Glacier - Portrait.png`，1350×2760，**屏幕区是透明的**：

- 屏幕透明区精确矩形 `(72,69)–(1278,2691)` = **1206×2622**，与 1206×2622 截图 1:1 吻合；
- 1260×2736 截图直接 resize 到 1206×2622（形变 0.15%，无感）；
- 屏幕圆角 mask 半径 145，`ImageChops.multiply` 乘进截图 alpha；
- 先 `base.paste(shot, (72,69))`，再 `alpha_composite` 叠边框（边框不透明区会盖住越界部分）；
- **灵动岛去重**：边框自带岛约 `x535–815 / y112–219`。截图自带岛时，把
  `(420,85)–(930,360)` 内所有 alpha 清 0（含淡阴影）得到 `clean` 边框；截图无岛时用原边框补岛。
  定稿：1260×2736 三张（灵动岛功能 / AI功能1 / AI功能2）→ `keep_island=False`；
  1206×2622 三张（首页 / 核心功能 / 设置页）→ `keep_island=True`。

### 阴影（双层高斯，必须带 pad）

```python
def soft_shadow(canvas, phone, x, y, blur, opacity, dx, dy, color):
    pad = int(blur * 3.2)                      # 关键：给 alpha 四周留衰减空间
    big = Image.new("L", (phone.width + 2*pad, phone.height + 2*pad), 0)
    big.paste(phone.getchannel("A"), (pad, pad))
    sa = big.filter(ImageFilter.GaussianBlur(blur)).point(lambda v: int(v*opacity))
    shadow = Image.new("RGBA", big.size, color + (0,))
    shadow.putalpha(sa)
    return composite_at(canvas, shadow, x + dx - pad, y + dy - pad)

# 环境层 + 接触层
soft_shadow(..., 88, 0.40, 8, 56, (2,20,62))
soft_shadow(..., 24, 0.18, 4, 20, (1,14,48))
```

旧版直接在 `phone.size` 上模糊，四边被硬裁 → 用户明确否决（错误档案 #3）。

### 整行绘制（「一」字 bug 的修法）

```python
def draw_line(d, x, y, text, font, color, stroke=2):
    d.text((x, y), text, font=font, fill=color, anchor="lt",
           stroke_width=stroke, stroke_fill=color)
```

**禁止** `for ch in text: d.text(...)`：Pillow 对单字符按该字形自己的墨迹顶部对齐锚点，
「一 / 二」这类扁字会被顶到行顶变成上划线（错误档案 #5）。
